# Qwen3-TTS Portable (fork)

Портативный Gradio-интерфейс для [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS) под Windows: клонирование голоса, пресеты, multi-speaker и дизайн голоса. Этот репозиторий — форк с живым воспроизведением длинных текстов.

## Источники

- Модель и официальный код: [QwenLM/Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)
- Портативная русская оболочка: [timoncool/Qwen3-TTS_portable_rus](https://github.com/timoncool/Qwen3-TTS_portable_rus)
- Коллекция моделей: [Hugging Face — Qwen3-TTS](https://huggingface.co/collections/Qwen/qwen3-tts)

## Что изменено в этом форке

- **CUDA Graphs** (`faster-qwen3-tts`) — быстрее официального generate на NVIDIA, с откатом на `qwen_tts`, если графы недоступны.
- **Живое воспроизведение** — чанки сразу идут в Web Audio, без пересоздания плеера на каждом куске.
- **Длинный текст** — нарезка по предложениям, очередь GPU → браузер, преролл, чтобы не заикаться на старте.
- **Пауза и стоп** — пауза не убивает генерацию, стоп гасит и GPU, и звук.
- **Русский текст** — даты, числа, URL, email и `@ники` читаются словами, а не ломают 1.7B.
- **Чанки без обрыва и без длинной дыры** — модель не бросает фразу на EOS и не тянет тишину до следующего куска.

## Запуск

1. Распакуйте архив.
2. `portable/install.bat` — зависимости (один раз).
3. `portable/run.bat` — интерфейс.

Модели качаются при первом запуске в `portable/models/`. Сами веса и встроенный Python в git не входят.

## Требования

- Windows 10/11
- 16 GB RAM (для 1.7B лучше 32 GB)
- интернет только на первую загрузку моделей

В `install.bat` выбирается поколение карты — ставится свой PyTorch/CUDA.

| Карта | Архитектура | CUDA в установщике | Заметки |
|---|---|---|---|
| GTX 10xx | Pascal | 11.8 | Работает, без нативного bf16, медленнее 30xx+ |
| RTX 20xx | Turing | 11.8 | То же: CUDA есть, графы/bf16 слабее, чем на Ampere |
| RTX 30xx | Ampere | 12.6 | Нормальный режим: CUDA Graphs + bf16 |
| RTX 40xx | Ada | 12.8 | То же, обычно быстрее 30xx при той же VRAM |
| RTX 50xx | Blackwell | 12.8 | Поддержано установщиком |
| Без GPU | CPU | cpu | Официальный `qwen_tts`, без графов, очень медленно |

AMD, Intel Arc и macOS в этой портативке нет — только NVIDIA CUDA или CPU.

VRAM важнее названия карты. Веса в bf16: **0.6B ~1.2 GB**, **1.7B ~3.4 GB**, плюс активации и клон (референс в контексте). Официально от **8 GB**.

| VRAM | Примеры | Что брать |
|---|---|---|
| 8 GB | 3070, 4060, 5060 | **0.6B**. 1.7B может влезть, но длинный клон легко упрётся в память |
| 10–12 GB | 3080 10 GB, 3060 12 GB, 4070 | **0.6B** для живого эфира (~1.3–1.5× realtime). **1.7B** ок по качеству, но около realtime — чаще преролл и короче чанки |
| 16 GB | 4060 Ti 16 GB, 4080, 5070 Ti | Оба размера. 1.7B уже комфортнее |
| 24 GB+ | 3090, 4090, 5080, A10 | Оба размера без ужима. VoiceDesign (только 1.7B) здесь же |

Модели в интерфейсе:

- **0.6B Base / CustomVoice** — быстрее, меньше память, без VoiceDesign
- **1.7B Base / CustomVoice** — качество и инструкции лучше
- **1.7B VoiceDesign** — голос по текстовому описанию, только эта размерность

Живой плеер не привязан к одной карте: если генерация быстрее realtime — очередь не пустеет; если нет (часто 1.7B на 8–12 GB) — больше преролл, возможны короткие заикания.
